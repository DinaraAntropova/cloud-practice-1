Хмарний сервіс: GitHub

GitHub — хмарна платформа для зберігання, розробки та спільної роботи над програмним кодом.

Модель хмарних послуг: SaaS — програмне забезпечення як послуга. GitHub також надає хмарне середовище розробки GitHub Codespaces.

Приклади сервісів і функцій: GitHub Repositories, GitHub Codespaces, GitHub Pages, GitHub Actions та спільна робота над проєктами.
